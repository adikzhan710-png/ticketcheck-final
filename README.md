# TicketCheck

Локальный учебный прототип выпуска, передачи и однократного использования билетов.
Он продолжает идею Endterm: организаторы и площадки используют общий статус билета.
Небольшое дополнение для Final — владелец может передать действующий билет другому аккаунту.
Платной перепродажи, инвестиционного токена и реальных платежей здесь нет.

## Запуск

Нужен Node.js 24 LTS с npm. Из папки проекта:

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd test
npm.cmd run demo
npm.cmd run typecheck
```

Для `npm ci` нужен интернет. Компилятор Solidity 0.8.28 входит в закреплённые npm-зависимости;
отдельная загрузка компилятора Hardhat не требуется.
Тесты и демонстрация создают локальную сеть Hardhat внутри процесса. Каждый запуск начинается
с новой сети; данные после завершения не сохраняются. Кошелёк, seed-фраза и реальные средства не нужны.
Тестовые аккаунты предоставляет Hardhat. Скрипт демо не выводит приватные ключи.

`npm.cmd run node` отдельно запускает RPC-сервер на 127.0.0.1. Для текущего автоматического
демо он не нужен: демо использует собственную временную сеть, а не этот RPC-сервер.
Стандартный вывод команды `node` содержит публично известные учебные ключи Hardhat;
не включайте этот вывод в видеозапись задания.

В этой среде Windows проверка выполнялась с адаптером для ошибки `realpath EPERM`:
`./scripts/check-windows.ps1`. Он запускает сборку, тесты, демо и проверку типов,
восстанавливая переменную окружения после завершения. Подробности — в `docs/VERIFICATION.md`.

## Сценарий

1. Организатор создаёт мероприятие и назначает сотрудника входа.
2. Организатор выпускает билет Алисе.
3. Алиса передаёт билет Бобу. Её прежнее разрешение на вход удаляется.
4. Попытка Алисы разрешить вход после передачи отклоняется.
5. Боб разрешает конкретному сотруднику погасить билет в течение короткого срока.
6. Сотрудник погашает билет; повторный проход отклоняется.

Разрешение действительно максимум 10 минут и может быть отменено владельцем.
В прототипе владение доказывается транзакцией с текущего тестового аккаунта.
Это не проверка личности и не доказательство физического присутствия на входе.
QR-сканер и графический интерфейс пока не реализованы.
